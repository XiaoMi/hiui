# Legacy Runtime Template Parity Ledger

## Scope

This ledger tracks the `HiuiLegacyPage` lightweight runtime parity work across the 9 managed page types only:

- `table-stat`
- `table-basic`
- `tree-table`
- `tree-split`
- `drawer-form`
- `drawer-detail`
- `full-page-edit`
- `full-page-detail`
- `feedback-status`

`data-visualization` is outside this runtime chain unless a separate runtime entry is introduced and governed by a dedicated parity ledger.

## Status Legend

- `done`: implemented and covered by direct evidence.
- `partial`: some code exists, but coverage or parity is incomplete.
- `pending`: not yet implemented.
- `blocked`: implementation requires a verified upstream API or project decision.
